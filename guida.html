Setup iniziale — una volta sola (15 minuti)
1
Crea un account GitHub gratuito
Vai su github.com e registrati con email e password. È gratis e non serve carta di credito.
2
Crea un nuovo repository
Dopo il login, clicca sul pulsante verde "New" in alto a sinistra.
— Nome repository: hotelfuturo
— Spunta "Public" (obbligatorio per GitHub Pages gratuito)
— Spunta "Add a README file"
— Clicca "Create repository"
3
Carica i 4 file nel repository
Nella pagina del repository, clicca "Add file" → "Upload files".
Trascina dentro questi 4 file: index.html, admin.html, data.json, guida.html
Clicca "Commit changes" in basso.
4
Attiva GitHub Pages
Nel repository, vai su Settings (in alto) → sezione Pages (nel menu laterale).
In "Branch" seleziona main e cartella / (root).
Clicca Save. Aspetta 2-3 minuti.
Il tuo link pubblico sarà:
https://TUONOME.github.io/hotelfuturo

Questo è il link da trasformare in QR code e da stampare per i ragazzi.
5
Genera il QR code
Vai su qr.io oppure qrcode-monkey.com (gratis).
Incolla il link https://TUONOME.github.io/hotelfuturo
Scarica il QR code come PNG e stampalo su un foglio A4 da appendere in aula.
Ogni giorno durante il corso
Apri admin.html sul tuo PC (basta doppio click, funziona offline)
Seleziona la sessione attiva cliccando sulla lista a sinistra
Aggiorna i punteggi con i bottoni +1 / +2 / −1 durante le sfide
Scrivi il nome del rappresentante di turno per ogni squadra
Dopo ogni sfida, copia la risposta migliore di Claude e salvala nella Dashboard Hotel
Clicca "Scarica data.json" in alto a destra
Vai su GitHub → repository → clicca su data.json → matita (modifica) → trascina il nuovo file
I telefoni dei ragazzi si aggiornano entro 30-60 secondi automaticamente
Consiglio: tieni aperto l'admin sul tuo PC e la landing page su un secondo tab del browser per verificare in tempo reale che tutto funzioni prima di mostrarlo ai ragazzi.
Domande frequenti
?
I ragazzi possono modificare i punteggi?
No. La landing page è solo in lettura. Solo tu con l'admin puoi modificare i dati.
?
Cosa succede se dimentico di caricare data.json su GitHub?
La landing page rimane ferma sull'ultimo aggiornamento — non si rompe nulla. I ragazzi vedono semplicemente i dati dell'aggiornamento precedente.
?
Funziona senza connessione internet?
L'admin funziona offline. La landing page ha bisogno della connessione per aggiornarsi (i ragazzi la aprono con il QR code dal loro telefono).
